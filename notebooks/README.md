# Lesson notebooks

The interactive notebooks (`.webnb`) that accompany every lesson, exactly
as they appear pre-loaded in each course's lab on Coursera. They walk
through the lesson's ideas with runnable examples and practice exercises.

A `.webnb` file is plain text, so it is readable right here on GitHub. To
view one fully rendered (with runnable cells), open it in the course lab -
or locally in VS Code with the
[Web Notebook extension](https://github.com/soney/vscode-webnb).

Notebooks link to each other and to their sample files by relative path,
so keep a course folder together when downloading.
