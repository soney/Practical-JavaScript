# Assignments

Every assignment in the specialization: 180 problems across 59
Coursera assignments. Each problem folder holds the same starter code you are
given in the course lab and its description as the folder's `README.md`.

The 44 practice assignments also publish their solutions, in a
`solution/` folder holding the finished version of each file you are asked to
edit. The 15 graded assignments do not.

Autograder tests are not published.

Paths are the ones you see in the course lab, unchanged:

```
assignments/Course <n>/Module <n>/<assignment>/<problem>/
```

so a description that says "Edit `Lesson 2.1/index.html`" names the folder it
is sitting in.
