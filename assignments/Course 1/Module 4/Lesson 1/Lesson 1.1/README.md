# Problem 1: Window Properties for Browser Width

Edit `Lesson 1.1/main-1.js`:

Define a function called `windowWidth` that takes no arguments.

The width of the browser window, in pixels, is stored in the `window.innerWidth` property. Inside `windowWidth`, `return window.innerWidth`.

Read `window.innerWidth` *inside* the function (not before it), so that each call to `windowWidth()` reports the window's current width.
