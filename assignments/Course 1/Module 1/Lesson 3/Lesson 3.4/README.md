# Problem 4: Image Attributes for a Laptop Photo

Edit `Lesson 3.4/index.html`:

Inside the `<body>` of your HTML file, create an `<img>` element that:
- Uses the `src` attribute to reference an image of a laptop (`laptop.png`) that is located in the same directory as your HTML file
- Includes an `alt` attribute that clearly describes the image for accessibility: `A laptop showing a blank screen`
