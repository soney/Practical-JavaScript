Concatenation means joining strings together into one longer string. In JavaScript, you can use the `+` operator to concatenate strings. For example, `'10' + '20'` creates the string `'1020'`.

The `+` operator behaves differently with numbers and strings:
- `10 + 20` creates the number `30`.
- `'10' + '20'` creates the string `'1020'`.

1. Create the starting variables:
   - Create a variable called `firstNumValue` and assign it the number `10`.
   - Create a variable called `firstNumString` and assign it the string `'10'`.
   - Create a variable called `secondNumValue` and assign it the number `20`.
   - Create a variable called `secondNumString` and assign it the string `'20'`.

2. Create and log these result variables:
   - Create a variable called `valueAddition` that adds `firstNumValue` and `secondNumValue`. This should produce the number `30`. Log `valueAddition` to the console.
   - Create a variable called `stringAddition` that concatenates `firstNumString` and `secondNumString`. This should produce the string `'1020'`. Log `stringAddition` to the console.
