Edit `Lesson 2.3/main-3.js`:

- Note 1: For this problem, you will **only** edit the JavaScript file, `Lesson 2.3/main-3.js`. **Do not modify the HTML file**, `Lesson 2.3/index.html`.
- Note 2: The testing/export block at the bottom is boilerplate for the grader. Add your code above that block. Do not modify or remove the testing/export block; the tests use that block to access your variables and functions.
- Note 3: The tests check your variable names and values, not whether you use `let` or `const`. None of these variables need to be reassigned, so `const` is a good choice. `let` is also accepted if the final values are correct.
- Note 4: In JavaScript, the `*` operator means multiplication, for example, `8 * 5` evaluates to `40`. Write `*` in your code for multiplication.

1. **Declare variables**:
   - Create a variable `rectLength` with numeric value `8`
   - Create a variable `rectWidth` with numeric value `5`

2. **Perform operations**:
   - Create a variable `area` that calculates the area of a rectangle (length times width) and log it to the console.
   - Create a variable `perimeter` that calculates the perimeter of the rectangle (2 times (length + width)) and log it to the console.
   - Create a variable `areaSentence` that says: `"The area of a rectangle with length 8 and width 5 is 40."`
     - Use `rectLength`, `rectWidth`, and `area` variables to construct this sentence. Log it to the console.
