# Problem 4: Strict Equality for Number Checks

Edit `Problem 4/main-4.js`:

- Note 1: For this problem, you will **only** edit the JavaScript file, `Problem 4/main-4.js`. **Do not modify the HTML file**, `Problem 4/index.html`.
- Note 2: The testing/export block at the bottom is boilerplate for the grader. Add your code above that block. Do not modify or remove the testing/export block; the tests use that block to access your variables and functions.

Define a function called `isTen` that accepts one argument, `input`.

The function should:

1. Return `true` only when `input` is exactly the number `10`.
2. Return `false` for every other value, including the string `"10"`.

Use strict equality, `===`, so the function checks both the value and the type.
