# Problem 2: Logical Operators for Discounts and Shipping

Edit `Lesson 3.2/main-2.js`:

- Note 1: For this problem, you will **only** edit the JavaScript file, `Lesson 3.2/main-2.js`. **Do not modify the HTML file**, `Lesson 3.2/index.html`.
- Note 2: The testing/export block at the bottom is boilerplate for the grader. Add your code above that block. Do not modify or remove the testing/export block; the tests use that block to access your variables and functions.

1. Use the variables `isMember` and `hasCoupon` (already provided in your file). Each is a **boolean** set by a helper function. Do not change how they are defined.  

2. Create two new variables:
   - `finalDiscount` should be `true` if the user is a member **or** has a coupon. Otherwise, it should be `false`.
   - `freeShipping` should be `true` if the user is a member **and** has a coupon. Otherwise, it should be `false`.

3. Log to the console based on the values:  
   - If the user qualifies for a discount, log `"User gets a discount!"`.  
   - If the user qualifies for free shipping, log `"User gets free shipping!"`.  
   - If neither applies, log `"No discount or free shipping available."`.
