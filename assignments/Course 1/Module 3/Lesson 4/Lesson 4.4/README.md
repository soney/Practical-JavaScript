# Problem 4: For...of Loops for Filtered Values

Edit `Lesson 4.4/main-4.js`:

- Note 1: For this problem, you will **only** edit the JavaScript file, `Lesson 4.4/main-4.js`. **Do not modify the HTML file**, `Lesson 4.4/index.html`.
- Note 2: The testing/export block at the bottom is boilerplate for the grader. Add your code above that block. Do not modify or remove the testing/export block; the tests use that block to access your variables and functions.

Create an array called `numbers` with these daily temperatures in Celsius: `[8, 13, 4, 21, 10, 17]`

Create another array called `filteredValues` and start it as an empty array.

Write JavaScript code that:

1. Uses a `for...of` loop to iterate through the array
2. Uses an `if` statement inside the loop to check whether each number is **greater than 10**
3. Adds each matching number to `filteredValues`
   - If your loop variable is called `number`, use `filteredValues.push(number)` to add it to the array.
