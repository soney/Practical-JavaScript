# Problem 2: Function Parameters for Unit Conversion

Edit `Lesson 5.2/main-2.js`:

- Note 1: For this problem, you will **only** edit the JavaScript file, `Lesson 5.2/main-2.js`. **Do not modify the HTML file**, `Lesson 5.2/index.html`.
- Note 2: The testing/export block at the bottom is boilerplate for the grader. Add your code above that block. Do not modify or remove the testing/export block; the tests use that block to access your variables and functions.

Define a function called `feetToInches` that takes one number parameter called `feet`. The function should convert a length in feet into inches. There are `12` inches in one foot.

Within the function:
- Create a variable called `inches` that multiplies `feet` by `12`. Use the `*` operator:

  ```js
  const inches = feet * 12;
  ```

- Log `inches` to the console.
- Return `inches` from the function.

For example, `feetToInches(5)` should log and return the number `60`.
