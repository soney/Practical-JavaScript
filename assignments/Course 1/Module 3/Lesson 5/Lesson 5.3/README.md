# Problem 3: Return Values for a Driving Age Check

Edit `Lesson 5.3/main-3.js`:

- Note 1: For this problem, you will **only** edit the JavaScript file, `Lesson 5.3/main-3.js`. **Do not modify the HTML file**, `Lesson 5.3/index.html`.
- Note 2: The testing/export block at the bottom is boilerplate for the grader. Add your code above that block. Do not modify or remove the testing/export block; the tests use that block to access your variables and functions.

The minimum driving age is `16`. Write a function named `canDrive` that takes one number parameter called `age` and uses a conditional to check it:

- Return `true` if `age` is greater than or equal to `16`.
- Return `false` otherwise.

For example, `canDrive(20)` should return `true`, and `canDrive(15)` should return `false`.
