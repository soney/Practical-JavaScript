# Problem 2: Semantic Headings for a Course Page

Edit `Lesson 3.2/index.html`:

You are creating a webpage for a University of Michigan course.

Add semantic heading elements to the `<body>`:

1. Add an `<h1>` element with the exact text `Course Overview`.
2. Add an `<h2>` element with the exact text `Introduction to Data Science`.

Add a `<style>` element inside the `<head>` section. Inside that `<style>` element, add CSS rules with these selectors, properties, and values:

1. For the `h1` selector:
   - Set `font-family` to `monospace`.
   - Set `font-weight` to `normal`.
   - Set `font-size` to `2em`.
2. For the `h2` selector:
   - Set `font-style` to `italic`.
   - Set `font-size` to `1.5em`.

Use `<h1>` and `<h2>` because they describe the meaning of the content. Do not use `<div>` elements with classes to pretend something is a heading.
