# Problem 3: Inline CSS for a Paragraph

Edit `Lesson 1.3/index.html`:

We normally do **not** use inline CSS (in the `style` attribute of an element) but we will practice inline CSS in this problem.

Inside the `<body>` element, add one paragraph (`<p>`) with the text `Learning CSS syntax`.

Add a `style` attribute to the `<p>` element. The `style` attribute should include these CSS declarations:

1. Set the `color` property to `blue`.
2. Set the `background-color` property to `yellow`.
3. Set the `font-weight` property to `bold`.
