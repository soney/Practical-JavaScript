# Problem 1: CSS Type Selectors for a Styled Page

Edit `Problem 1/index.html`:

Inside the existing `<style>` element:

1. Add a CSS rule for the `h1` selector with these declarations:
   - Set the `color` property to `blue`.
   - Set the `font-family` property to `Arial`.
2. Add a CSS rule for the `p` selector with these declarations:
   - Set the `color` property to `green`.
   - Set the `font-size` property to `16px`.

The resulting page should look similar to this image:
