# Problem 3: CSS Link Selectors for Navigation

Edit `Problem 3/index.html`:

Use the existing `<style>` element in the `<head>` section to style the links on the page.

Your CSS should set these properties and values:

1. The element with `id="university"` should have:
   - `color` set to `blue`
   - `font-weight` set to `bold`
2. The link with `id="si"` should have:
   - `color` set to `green`
   - `text-decoration` set to `none`
3. The link with `id="lsa"` should have:
   - `color` set to `red`
   - `text-decoration` set to `none`
